Cara Mengambil Cookie / Token Sesi Akun Suno

Ikuti langkah mudah ini untuk mengizinkan SuDownloader membaca folder & playlist akun Anda:

Pilih salah satu metode termudah:
⚡ Metode 0 (Paling Mudah): Gunakan Ekstensi Khusus "SuDownloader Connect"

Ekstensi khusus ini 100% bersih & ringan tanpa tombol tambahan di halaman Suno:

  1. Buka chrome://extensions/ di browser & aktifkan Developer mode.
  2. Klik Load unpacked & pilih folder: e:\Xampp\htdocs\sudownloader_connect_extension.
  3. Buka tab Suno (suno.com) dan pastikan sudah login.
  4. Buka atau refresh SuDownloader — otomatis tersambung instan!
📋 Metode 1: Lewat Ekstensi Cookie-Editor (Manual)
  1. Buka https://suno.com (pastikan sudah login).
  2. Klik icon ekstensi Cookie-Editor di toolbar browser Anda.
  3. Klik tombol Export (bisa pilih format JSON atau Header String).
  4. Langsung klik tombol 📋 Tempel di SuDownloader. Sistem otomatis membaca JSON maupun string cookie dan menukar tokennya ke Clerk!
🎯 Metode 2: Lewat DevTools Tab Network (100% Pasti Berhasil)
  1. Di halaman suno.com, tekan tombol F12 > klik tab Network.
  2. Refresh halaman atau klik salah satu playlist/lagu di Suno.
  3. Di kolom pencarian Network, ketik studio-api atau feed atau client.
  4. Klik salah satu request di daftar, lalu di tab sebelah kanan (Headers), cari baris Authorization: (format: Bearer eyJ...) ATAU baris Cookie:.
  5. Copy seluruh nilainya dan tempel ke kolom SuDownloader!
🔒 Keamanan Data Anda

Cookie & Token Anda hanya disimpan di browser Anda (LocalStorage) dan dikirim langsung ke server PHP lokal (localhost:8000) tanpa pernah dikirim ke server pihak ketiga mana pun.
